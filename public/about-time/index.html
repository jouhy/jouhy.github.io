    * 밑줄과 굵은 글씨로 강조된 부분은 **제가 담당한 내용**입니다.

    AAMLA: An Autonomous Agentic Framework for Memory-Aware LLM-Aided Hardware Generation2025.04 — 2025.06
    Github Paper | Paper
    자연어 기반 하드웨어(Verilog) 생성 과정에서 Out-of-Memory 문제를 자동으로 회피하면서, 최적의 파인튜닝 전략을 선택하고 수행하는 프레임워크를 제공합니다.
    • 기존 LLMem을 확장해 LoRA, DoRA, MeZO, TokenTune, APOLLO의 메모리 사용량을 정확하게 예측하는 모델 구축
    • 각 fine-tuning 방법의 peak memory/accuracy/latency를 미리 분석하여 "accuracy-latency atlas" 생성
    • 전체 아키텍처를 세 단계로 구성했으며, RTL 코퍼스 전처리 → 메모리 기반 Fine-Tuning 전략 선택 → RTL 생성·기능 검증·합성의 순서로 설계
    GOLD: Green Optimization of Language Models Serving on Devices2024.07 — 2024.11
    Detail | Paper
    CPU와 GPU 전력을 조절하여 심층 강화 학습을 통해 온디바이스에서 LLM 추론 시 에너지 효율을 최적화합니다.
    • Nvidia AGX Orin에서 LLaMA-2-7B 모델로 추론 시 CPU와 GPU clock에 따른 성능 및 에너지 데이터를 수집 및 분석
    • 제한된 배터리 용량 환경에서 LLM 추론 시나리오 설계
    • 과도한 정책 업데이트 방지를 위한 PPO 기반 심층 강화 학습을 적용해 정책 최적화
    • 목표 대비 4% 높은 성능과 배터리 수명 1.39배 증가 달성
    From Voice To Face2024.01 - 2024.04
    Detail | Github
    사용자 목소리를 기반으로 GAN을 이용해 얼굴을 생성하고, 생성된 얼굴을 사용자가 선택한 동영상에 통합하는 서비스를 구현합니다.
    • VoxCeleb 데이터를 사용해 음성 파일을 mel-spectrogram으로 음성 특징 추출
    • GAN 기반의 Speech Fusion to Face와 SimSwap 모델을 채택해 얼굴 생성 및 동영상 합성 작업을 수행
    • 생성 얼굴과 합성 영상을 웹을 통해 사용자에게 제공하고 사용자 피드백 수집
    • dilb 라이브러리를 활용해 생성 얼굴의 특징과 사용자 평가를 분석한 결과, 생성 얼굴의 눈이 클수록 높은 점수를 받으며, 목소리에 어울리는 생성 얼굴보다 사용자 취향이 서비스 만족도에 큰 영향을 미칠 수 있음을 확인
    3D Object Detection from Stereo Images using Teacher-Student Training for Semi-supervised Learning2022.10 - 2023.06
    스테레오 이미지를 기반으로 2D 정보를 3D로 확장하고, 반지도 학습을 통해 저비용 3D 객체 검출을 수행합니다.
    • Teacher-Student 네트워크를 기본 모델로, DSGN++를 백본 모델로 활용해 스테레오 이미지 기반 3D 객체 검출을 수행
    • DSGN++의 copy and paste 샘플링 방법을 바운딩 박스 형태에서 폴리곤 형태로 개선
    • Teacher 모델의 성능 향상을 위해 IoU와 depth confidence 모듈을 추가
    Anomaly Detection Based on Dash cam2022.03 - 2022.09
    Paper
    주행 중 사고를 예방하기 위해, 이상 차량을 예측하고 운전자의 상태를 파악하여 경고하는 알림 시스템을 구축합니다.
    • 시뮬레이터를 활용해, 주행 중 운전자 전방에서 사고가 발생하는 상황을 재현한 사고 이미지 데이터를 생성·수집
    • Eyetracker를 통해 운전자의 시선 정보를 수집하고, 눈 깜박임과 시선 추적을 기반으로 운전자 집중도를 평가하는 알고리즘을 제안
    • GRU 모델 기반의 오토 인코더를 통해 이상 차량이 탐지되면, 운전자의 집중도에 따라 비정상 상황에 대한 알림 시스템을 구축
